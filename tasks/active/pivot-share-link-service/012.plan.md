# Build order: mdcv -> page (folded with the new features)

Everything lands in the new `page` shape directly (no throwaway prototype on
`mdcv`). New `_dev_page*` collections live ALONGSIDE the old `_dev_md_cv*` during
the build; cutover + the paused migration come last.

Slices (each should type-check; `just check`):

1. SCHEMA — `dto/page.dto.ts` (`PageDto`/`PagePdfDto`) + `_dev_page` /
   `_dev_page_pdf` in db.ts. Indexed lc routing keys + raw display values, drop
   vestigial `html`. (this slice)
2. RESERVED USERNAMES — dev generator -> committed `reserved-usernames.ts`
   (`Set`), from our route slugs + Big Username Blacklist + LDNOOBW; enforced in
   nik create/update (lc, exact).
3. SERVICE — `page_service.ts`: save/update/default/pdf with the
   lowercase-index + raw-display logic (insert: lc->check->store display+lc).
4. PUBLIC SERVING + RENDER MACHINE — resolve by lc index -> canonical redirect
   (302/307) when incoming != display -> render machine (serve_artifact |
   render_md) -> CDN cache headers: `Deno-CDN-Cache-Control: public,
   s-maxage=${CACHE_S_MAXAGE ?? <long default>}` + `Deno-Cache-Tag:
   page-<id>,user-<id>`.
5. INVALIDATE-ON-WRITE — helper POSTing `cache.localhost/invalidate/http` with
   `page-<id>` (and `user-<id>` for nik rename); called from every mutation.
   Migrate the existing pdf Web-Cache to this scheme.
6. ROUTERS — `/v1/page` (rename mdcv router); wire service.
7. CUTOVER — switch mounts to page, take `post-pivot` schema photo, hand off to
   the paused [[kv-restore-migrate]] for data.

Index set on `_dev_page` (each earns its place per [[008.analysis]]):
`_id`(P), `user_id`(S), `is_published`(S), `default_by_user_id`(P),
`default_by_username`(P, lc), `by_username_and_name`(P, [lc_user, lc_name]).
Display: `display_username`, `display_name` (unindexed). Cache by tag, not
render_version.
