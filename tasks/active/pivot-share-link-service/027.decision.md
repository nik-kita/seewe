# Drop the legacy mdcv backend now; rebuild the UI from scratch later

User pivot (answering "what next"): do NOT rebrand the existing frontend — it will
be rebuilt from scratch. So the existing `src/` UI is abandoned (left in tree, no
longer maintained), and the immediate work is removing the dead mdcv backend that
nothing in the new domain uses.

Removed from PRODUCTION: `/v1/mdcv` routes (`routers/mdcv/`), `md-cv_service`, the
old `spa_subserver.tsx` serving, and the `_dev_md_cv*` collections in `db.ts`.

Key constraint honored: the migration tool still needs the OLD shape to convert a
dump. So the old schema was relocated to `dev/legacy_md-cv.dto.ts` and
`kv_transform.ts` got its own `make_legacy_db(kv)` — production `db.ts` is now
mdcv-free, and the one place that remembers mdcv is the retiring migration tool.

Not removed (deliberately, separate cleanup): the raw `nik` primary index +
`users_service.find_by_nik` (defined, currently uncalled) — that's user identity,
not mdcv legacy. Executed in [[028.log]].
