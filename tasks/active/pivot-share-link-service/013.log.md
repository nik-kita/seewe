# Slice 1 done: `page` schema

Added `api/dto/page.dto.ts` (`PageDto`/`PageEntityDto`/`PagePdfDto`) and the
`_dev_page` + `_dev_page_pdf` collections in `db.ts`, alongside the old
`_dev_md_cv*` (dropped at cutover).

Shape vs the CV-era record:
- dropped vestigial `html`.
- identity split: raw `display_username`/`display_name` (unindexed) + lowercased
  routing keys `default_by_username` / `by_username_and_name` (indexed).
- renamed `as_default_by_*` / `as_regulary_by_name_username` ->
  `default_by_user_id` / `default_by_username` / `by_username_and_name`.
- pdf blob collection keyed by `page_id` (was `mdcv_id`).
- `PageDtoForPartialUpdate` relaxes the fixed-length compound tuple for partial
  updates (mirrors the existing mdcv handling), needed for the nik-rename rewrite.

Indices (each earns its place, [[008.analysis]]): `_id`(P), `user_id`(S),
`is_published`(S), `default_by_user_id`(P), `default_by_username`(P),
`by_username_and_name`(P). No render_version field — CDN cache tags handle
invalidation ([[011.decision]]).

`deno check mod.ts` clean. Next slice ([[012.plan]]): reserved-usernames
generator + enforcement.
