# Drop kvdex; hand-rolled explicit raw-KV storage (zod kept)

The new `page` version does NOT use kvdex. Storage, keys, and indexing become
explicit and specific to the app's actual queries. Zod stays — for validation at
the boundary (write, and defensive parse on read), not as an ORM.

## Why

kvdex hides the key layout and maintains primary/secondary index copies behind
generic helpers. The user wants the opposite: keys and indexes designed by hand
around the real access patterns, nothing generic or implicit.

## Actual query inventory (drives the key design)

users:
- by `_id`, by `email`, by `nik`; insert; update(`_id`); list-all.
  `email` and `nik` are unique.

page (today `_dev_md_cv`):
- by `_id` (get/update/delete/toggle/pdf ops)
- list by `user_id` (dashboard; and published-only filter for public profile)
- default by `user_id` (anon user's single default — public `/id/:user_id`)
- default by `username` (public `/:username`)
- named by `[username, name]` (public `/:username/:name`)
- writes: add, update(`_id`), set/clear default, delete, and on nik change
  rewrite `default_by_username` + `[username,name]` for all of a user's pages.
  `default_by_username`, `[username,name]`, `default_by_user` are unique.

page_pdf (today `_dev_md_cv_pdf`):
- get/upsert/delete by page id; blob can exceed the 64KiB KV value cap.

## Open trade-offs to settle before coding (raised in chat)

1. Index entries store the page id (one extra get) vs. denormalize the full
   record under each lookup key (fast public read, costlier consistent writes).
2. Atomic maintenance of record + secondary/unique keys via `kv.atomic()` +
   `check` — this is the real work kvdex was hiding; uniqueness needs check-then
   -commit.
3. PDF blob: hand-rolled chunking across `["page_pdf", id, n]` entries vs. keep
   it out of KV. The 64KiB cap is the constraint
   [[seewe-kvdex-write-only-validation-and-kv-limits]].

## Consequence

Affects the paused [[kv-restore-migrate]] transform (old kvdex layout -> new
explicit layout). Not actioned now (task paused).
