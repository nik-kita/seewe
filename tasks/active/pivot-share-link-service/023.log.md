# Slice 6 done: page router (/v1/page)

Ported the mdcv write API to the page domain. New `api/routers/page/`: 8 route
defs (`post_page`, `put_page`, `put_page_default`, `get_page`, `delete_page`,
`get_my_pages`, `put_page_pdf`, `delete_page_pdf`) + `page_router.ts`, mounted
in v1.ts as `/v1/page` ALONGSIDE `/v1/mdcv` (old stays until cutover).

- request schema `PageInputDto` (md/css/is_published/name) — identity/routing
  derived server-side, never from the client.
- handlers wire `page_service`; `owned_page()` helper centralises the 404/403
  ownership check; pdf upload keeps the 5MB cap + `%PDF-` magic check.
- added `page_service.rename` (named-page rename: replace `display_name` + lc
  compound, purge_user) and `page_service.remove` (delete page + pdf blob,
  purge_user). `put_page` calls rename when a named page's `name` changes.

Bug found + fixed: kvdex `updateByPrimaryIndex` MERGES arrays by default, so
rename appended to `by_username_and_name` (`[u,old,u,new]`) and the relaxed
update schema let it pass — would corrupt every rename's slug. Fixed with
`{ mergeOptions: { arrays: "replace" } }`. Verified: rename replaces the compound
exactly, new lc resolves, old gone, display raw; remove deletes. 5/5 smoke.

`deno check mod.ts` + `deno task test` (22) clean. Full authed e2e of the router
deferred (needs a real JWT) — do at cutover with the running server.

Doc: `/v1/page` is now in the OpenAPI; frontend types (`just gen-types`) regen
with the deferred UI rebrand.

Next: slice 7 cutover — mount page_subserver (replace spa_subserver), nik-rename
