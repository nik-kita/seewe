# Slice 4c handler done: page_subserver

Added `api/spa_subserver/page_subserver.tsx` — the `page`-domain public serving
(rework of spa_subserver). Routes `/id/:user_id`, `/:username/:cv_name`,
`/:username`, `*`->serve_static.

- Each route builds `ServeInput` for the `serving_machine`: a route-specific
  `resolve` (lc page-index lookup — `default_by_user_id` / `by_username_and_name`
  / `default_by_username`), a `display_of` selector, raw `incoming` segments,
  `load_pdf = page_service.get_pdf`.
- `respond()` turns the decision into a Response: `redirect`->307 (keeps the
  `.pdf` suffix), `artifact`->pdf bytes (inline / attachment for `.pdf`),
  `site`->md_to_html in SimpleLayout; `fallback`->null so the route applies the
  not-found nuances (find_by_nik_lc -> redirect to /username, or render the
  published-pages profile list, or notFound).
- Reads cast `?.value as PageEntity` (kvdex relaxed-update schema types `_id?`;
  reads are defensive — memory seewe-kvdex-write-only-validation-and-kv-limits).

NOT mounted in mod.ts yet (cutover = slice 7); the old spa_subserver still
serves. Verified via `page_subserver.request()` integration smoke (12/12, real
KV, cleaned up): canonical render, case redirects (username + name), /id (nemo
render + nik->username), pdf inline/attachment, md+.pdf html, 404, named-missing
redirect, profile list. `deno check` clean.
